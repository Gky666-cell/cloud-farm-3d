# v0.25.0 第一轮游戏体验优化（待玩家验收）

基于 `art-v1-test` 最新提交 `b1f504316193c9ec197fd3f2e8555f9b0985798c`，独立分支 `experience-v0.25.0`。构建版本为 `v0.25.0-experience-test`。新 PR 以 `art-v1-test` 为目标，原 Draft PR #1 继续保留；没有合并或改动正式 main / GitHub Pages。

## 实际问题与本轮修复

| 实际发现 | 修复 |
| --- | --- |
| 弯折连续播种在松手时再画起终点直线，误种未划过的田 | 松手只补最后一段；增加真实 pointer 事件序列回归 |
| 建筑屏幕矩形的空白角也会触发，动物位置与命中时刻不同 | 建筑改为投影包围体的凸轮廓；动物按最后上传的姿态和朝向命中；保留小目标触控容差 |
| 放养后圈里消失的第一只动物仍能命中 | 点击检测跳过已放养的动物 |
| 鸡/牛放养路线首尾不接，回到循环起点时跳跃 | 周期曲线连接首尾位置和切线；接近农田、预警结束与驱赶退场使用平滑过渡 |
| 动物滑行且通过整体缩放表现起伏 | 沿移动方向转身，移动速度影响步态，命名腿/蹄和尾部轻量变换；身体比例保持固定 |
| 动物脚和接触阴影高于/低于场景表面 | 用精修模型实际最低点落地；腿部步态限制最低点；按院子地面高度放置阴影 |
| 1366×768 默认视角裁掉建筑，主屋/花架侵入第一排农田 | 全景按岛屿范围和宽高比取景，独立经营场景适配宽屏；主屋向西北微调，移开花架、花箱与踏石；农田底座贴地 |
| 升级产量与收取按钮数字不一致 | 鸡蛋、牛奶、羊毛、水果全部使用实际设施等级产量 |
| 打开的生产面板到时未更新，周期替换操作卡容易打断点击 | 状态变化时刷新，倒计时仅更新文字，保留滚动位置；修正工坊倒计时选择器 |
| 菜单版本号把标题挤成竖排，低屏幕菜单越界 | 标题/模型链接分列，版本提示另起一行；菜单限制可用高度并可滚动；播种时收起重叠的桌面键位提示 |
| 浏览器拒绝写入存档时静默失败 | 显示未保存提示，成功重试后清除提示 |

## 保留与编辑方式

全部 17 个 GLB 和对应 GLTF、原始生成源码、LOD、旧模型失败回退、七个场景和经营玩法均保留。没有替换精修网格，也没有引入图片模型、纹理或额外图形库。六建筑生成器已重新运行，通过语义复现检查；导出浮点尾差没有写回模型文件。

`assets/art-v1/motion.js` 在现有命名部件上添加游戏运行时步态，缓存部件信息，沿用静态/动态两批绘制。腿/蹄配对变换，转向时同步旋转法线。GLB 本身仍是可在 Blender 中编辑的原始静态模型，不含骨骼或烘焙动画；修改部件名称后需同步适配动画部件映射。近远景都经过法线、地面接触、三角面数和源网格不被修改的验证。

沿用 `yun-farm-3d-art-v1-test` 测试存档键；正式存档键只读。`roam.animals.*.retreatAt` 是兼容旧存档的可选时间戳，其余经营字段和计时保持原结构。不同域名的 localStorage 不互通；旧私有测试站的进度不会自动搬到公开预览域名。

## 真实浏览器验收（2026-10-15）

在 Codex 内置 Chromium 浏览器通过本地 HTTP 服务器打开实际游戏，桌面视口 1366×768，另检查 390×844 窄屏。实际操作包括：

- 加载原创 GLB；七场景 WebGL 画面；主屋/农田避让、牛棚和羊圈全景、菜单换行及窄屏菜单。
- 点击农田 1 种胡萝卜，等待 8 秒后收获，金币 500 → 490 → 514。
- 点击移动小鸡、奶牛、绵羊打开对应个体卡；批量喂食后等待真实计时，收取鸡蛋 3、牛奶 4、羊毛 6。
- 收蛋后刷新页面，金币与鸡蛋库存恢复；种下苹果和橙子树，等待后分别采摘 3 个，进入下一次结果周期。
- 用 2 枚鸡蛋制作香香蛋卷，等待后收取成品 1；进入订单站交付牛奶 1，订单数变为 1，金币 +45、库存牛奶 4 → 3。
- B 键打开仓库，Esc 关闭、A 平移与 R 复位；菜单/场景往返；控制台未记录 warn/error。

桌面及窄屏截图由浏览器直接截取，交付在本轮聊天的输出文件中。物理手机、多点触控、长时间帧率/发热、不同显卡、Safari/Firefox 与 Blender 人工编辑没有实测。

没有增加全场景碰撞或网格级遮挡拾取系统。建筑仍使用投影包围体，极端重叠物体的点击优先级、放养动物经过装饰的避让，以及近景美术观感仍请玩家重点验收。当前保留约 30 FPS 的绘制节流、DPR 上限 1.5，动态姿态约每 80–100ms 更新；这不是物理手机实测帧率。

## 测试入口与本地运行

- [公开游戏预览](https://raw.githack.com/Gky666-cell/cloud-farm-3d/experience-v0.25.0/index.html)
- [原始模型浏览器](https://raw.githack.com/Gky666-cell/cloud-farm-3d/experience-v0.25.0/preview.html)

使用原有 raw.githack 公开仓库预览方式，无需私有站点登录。第三方服务可能有确认页、缓存或地区网络限制；以页面标题/菜单中的 `v0.25.0-experience-test` 核对版本。

若公网服务不可达，在 Windows 安装 Python 3 后：

```powershell
git clone --branch experience-v0.25.0 --single-branch https://github.com/Gky666-cell/cloud-farm-3d.git
cd cloud-farm-3d
py -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/index.html`；模型页为 `http://127.0.0.1:8000/preview.html`。系统若只有 `python` 命令，将 `py` 换成 `python`。无需 npm、构建工具或账号；不要直接双击 HTML。
