# 原创建筑 V1.3 · 主岛与场景美术集成
本版本以 `art-v1-test` 为测试分支，正式 `main` 页面仍是 v0.18.0。继承 V1.2 的主屋、普通树、苹果树、鸡牛羊、农田模型，增加六栋/类可编辑原创建筑：

| 模型文件名 | 作用 | 三角面 | 可编辑网格部件 |
|---|---|---:|---:|
| coop-house.glb | 鸡舍 | 1,520 | 51 |
| cow-barn.glb | 牛棚 | 1,924 | 62 |
| sheep-barn.glb | 羊圈小屋 | 2,084 | 64 |
| workshop-house.glb | 加工坊 | 2,028 | 65 |
| windmill.glb | 风车 | 1,576 | 56 |
| well.glb | 水井 | 856 | 34 |

所有 GLB 都有对应嵌入二进制的 GLTF 文件，均由项目原创参数网格构造，使用统一奶油色墙体、木梁、暖红屋顶、鼠尾草绿配件的微缩农场风格。不依赖第三方素材，也不以渲染图片冒充模型。

## 可复现和编辑
运行 `node tools/build_buildings.cjs` 可从完整原始几何源码重新生成上述六个 GLB 与 GLTF 文件。可在 Blender 中导入 GLB 并分开修改屋顶、门窗、标识、家具、风车帆叶和水井水面；导出时使用 Y 向上、+Z 朝正面、模型地面原点，保持纯色三角网格和命名节点，适配现有轻量 WebGL GLB 解析器。

## 游戏集成
- 主岛鸡舍、牛棚、羊圈、加工坊、风车和水井：优先显示新 GLB。
- 鸡舍独立场景：沿用新的鸡舍；保留鸡舍周边围栏和饲喂道具。
- 牛、羊独立牧场：后方大型棚屋按比例复用新模型，牛奶/羊毛生产道具保留。
- 保留旧版几何模型作为逐个建筑的失败回退；`FarmArtV1.load()` 整包加载失败时退回旧画面。
- 保留农作物、经营任务、动物经营、触摸、相机固定角度和独立测试存档 `yun-farm-3d-art-v1-test`。

## 校验范围
提交包含可在 GitHub Actions 执行的 Node VM 回归测试，用于加载所有 GLB/GLTF、经营逻辑、场景 mesh 和资源失败回退；自动化以 WebGL/DOM 模拟对象运行，**不能替代真实手机的显示、FPS 和触控验证**。正式上线前须用实际安卓浏览器逐项体验，确认触摸命中、模型遮挡和性能。

测试预览入口：`preview.html`。主岛测试入口：`index.html`。原 V1.1 ZIP 仍为旧资源归档，不包含本次六栋建筑。
