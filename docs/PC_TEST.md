### 电脑操作

| 目标 | 操作 |
| --- | --- |
| 点击建筑、农田、动物 | 鼠标左键单击 |
| 平移镜头 | 按住鼠标左键拖动，或 WASD / 方向键 |

| 视角复位 | R 或 0 |

快捷键会避开输入框、文本框和系统组合键；游戏正在显示操作面板时不抢占面板的方向键。窄屏手机保持原来的触控交互。

## 建议的电脑验收顺序

1. 用 Chrome 或 Edge 进入游戏，点击欢迎页的「进入我的空岛」。确认主屋屋顶与墙体相连，牛眼睛可见且尾巴连接，羊四肢与羊毛不再只是圆球。
2. 放大查看鸡舍、牛棚、羊圈、加工坊、风车和水井。换到模型预览页面旋转模型，观察背面有无断裂。
3. 在农田完成一次种植、等待成熟和采摘；用 M 打开菜单，分别进入鸡舍、牛棚、羊圈、果园、工坊和订单，验证经营按钮。
4. 按住鼠标左键拖动、使用滚轮缩放、WASD、R、Esc，观察命中区域、场景切换和视角。
5. 刷新页面，检查测试存档是否保留；对照正式版确保互不覆盖。

## 常见问题

- **出现「资源加载失败 · 使用原模型」**：当前网络未能获取 GLB；可刷新或在 GitHub 下载此分支 ZIP 后用本地 HTTP 服务测试。此时经营仍可运行，但不代表美术测试通过。
- **白屏或提示无法启动 3D**：优先使用最新版 Chrome/Edge 并开启硬件加速，按 F12 查看 Console 错误。
- **打开的是 GitHub 代码页**：请用上面的网页预览地址而不是 `github.com/.../blob/...`。
- **预览显示老版本**：可能是 CDN 缓存；等待缓存更新或使用固定提交的 rawcdn 地址核对，切勿直接覆盖正式版。

## 本地 HTTP 服务（可选）

在 Windows 下载 `experience-v0.25.0` 分支（基于最新 `art-v1-test`） ZIP，解压后打开此文件夹的 PowerShell（已安装 Python 3）：

```powershell
py -m http.server 8000
```

浏览器访问 `http://localhost:8000/index.html`；模型预览为 `http://localhost:8000/preview.html`。不要直接双击 HTML 文件，以免浏览器限制 GLB 的 fetch 读取。

**验证边界：** GitHub Actions 的 Node VM 回归检查不等于真实 Windows 浏览器、WebGL 或 PC GPU 帧率实测。电脑实际外观与操作需人工反馈。
