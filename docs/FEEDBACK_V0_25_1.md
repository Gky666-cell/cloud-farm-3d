## 玉米彩色拉线

截图中的长彩线来自玉米苞叶的双色数组。`leaf()` 将两个十六进制颜色字符串直接交给了把数组视作 RGBA 的 `face()`，每个顶点少写两个数，破坏了位置/法线/颜色共 10 个浮点数的 WebGL 顶点布局。现按叶片两面分别解析颜色，底层 `face()` 也明确区分数字颜色与字符串调色板。保留玉米模型、四种作物及生长表现。

新增测试覆盖四种作物的五个生长阶段、全部 16 块农田、导入资源与失败回退、混种、收获重播和存档恢复；检查顶点步长、有限数值、坐标范围及归一化 RGBA。修复前，玉米测试能复现三角形数据余数为 18 的失败。

## 行走

圈舍中的微小椭圆自转改为有实际位移的圆滑路线：沿途行走、减速、停留约 2.7–4.6 秒、再出发。身体朝向跟随路线切线，停留时保持朝向。三类动物、不同个体错开时间与路线。

脚步按实际行进距离计算，牛羊四拍交错、小鸡双脚交替；支撑阶段足端向后抵消身体位移，摆动阶段抬脚回收。腿根固定，用命名网格的轻量形变连接脚部，法线同步修正。去除整只动物的周期性伸缩，只保留很轻的身体起伏、待机点头和尾部摆动。主岛放养也使用实际位移累计步幅，既有放养与偷吃逻辑保留。

不增加骨骼、物理引擎、模型三角形或额外绘制调用。这里是轻量近似步态，急弯仍可能有轻微侧滑；尚未加入全场景碰撞/寻路或完整骨骼 IK。

## 测试入口与运行

游戏应显示 `v0.25.1-feedback-test` 和「原创美术 V1.4」。测试沿用 `yun-farm-3d-art-v1-test` 存档键，升级不会清档。浏览器的协议、域名或端口变化会使用另一份本地存档；继续旧进度请使用原来的入口。

仓库公开预览仍为 <https://raw.githack.com/Gky666-cell/cloud-farm-3d/experience-v0.25.0/index.html>。该第三方入口在本环境曾超时/TLS 失败，不能承诺可用；分支名保留，页面版本已升至 0.25.1。正式 GitHub Pages 不发布此测试版。

可靠运行方式：下载本分支 ZIP，解压后在包含 `index.html` 的目录执行：

```powershell
py -m http.server 8000 --bind 127.0.0.1
```

然后打开 <http://127.0.0.1:8000/index.html>。若使用 `python` 命令，将 `py` 替换为 `python`。不要直接双击 HTML。

开发验证：

```sh
node tests/art-v1.test.cjs
node tests/experience-v025.test.cjs
node tests/feedback-v0251.test.cjs
python -m pip install numpy==2.3.5
python tools/check_animal_repro.py
```

修改动物源文件后用 `python tools/build_art.py --animals-only` 导出六组动物，不会重建房屋和建筑，也会保留完整资源清单。
